# 资料服务接口

资料源支持单段 HTTP Range，返回 Content-Range 和内容摘要 ETag。If-Match 可以限定本次范围读取的来源版本，版本不符返回 412，越界返回 416。该行为只负责传输，不替接收应用决定领域对象是否完整。

来源目录在新发布日期增加最终版，并可能更新快速版的参考框架。该目录是产品级事实，SP3 解析保留哨兵和标记，不自行将它们解释为有效零值。

示例采用 SP3-c 文本列格式，位置为千米，钟差为微秒，零位置与 999999.999999 有不同缺测语义。/releases 提供产品级框架、解类型及发布时间切面；它们不能从文件名猜测。CLK 资料仅作为产品依赖原件收取，不要求实现定位解算。

本地服务的资料入口为 `/products/rapid.sp3`。`fixtures/ordinary.json` 记录当前可预览的资料；`fixtures/transition.json` 保存资料源连续两个发布日期。调用 `POST /control` 并传入 `{"action":"advance"}` 推进发布日期，`inspect` 返回实际请求记录，`reset` 恢复本地源；控制入口不属于远端标准协议。来源分段、延迟和断连均可用场景条目的 `chunks`、`delayMs`、`disconnect` 配置，不需要依赖实际网络故障。

原件目录采用内容摘要寻址，接收凭据独立记录来源、媒体类型和预览结果。单份资料接收不表示来源范围已经读完，也不推断缺失资料的业务含义。
